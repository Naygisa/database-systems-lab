# 数据库系统实验小作业

使用 MySQL 8.0.43 和 Navicat Premium Lite 完成。脚本以 UTF-8 保存。

## TPC-H 综合实验

在新的 TPCH 数据库上按编号执行 [tpch](tpch) 中的脚本。任务 2 的两份脚本按插入数据、检查订单的顺序运行。任务 3 在同一会话中先运行准备语句，再逐条运行预期报错的语句，最后执行回滚。任务 6 包含余额查询和无订单顾客查询加分项。任务 7 使用任务 2 设置的初始库存。
